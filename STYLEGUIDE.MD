# FitnessWeb Style Guide

## Colour Palette

### Lime Green
Hex: `#B6FF3B`

Used for important elements such as buttons, highlighted text, links and accents.

### Dark Background
Hex: `#0D1117`

Used as the main background colour of the application.

### Card Background
Hex: `#161C23`

Used for workout, goal and fitness tip cards.

### White
Hex: `#FFFFFF`

Used mainly for headings and important text.

### Grey
Hex: `#8994A2`

Used for descriptions and secondary text.

## Fonts

FitnessWeb uses system fonts including Segoe UI and other sans-serif fonts.

### Large Heading
Approximately `48px - 82px`

Used for the main hero heading.

### Section Heading
Approximately `32px - 42px`

Used for major section titles.

### Body Text
Approximately `16px - 18px`

Used for descriptions and general page content.

## Design Style

FitnessWeb uses a modern dark fitness theme.

The dark background provides strong contrast while the lime green accent highlights important content and actions.

Cards are used to separate workouts, goals and fitness tips so users can quickly understand each section.
